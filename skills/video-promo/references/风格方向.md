# 风格方向与叙事结构

## 风格方向

1. **Apple 发布会极简**：大留白、单一强调色、产品界面居中。
2. **电影预告片**：黑场、快切、低频鼓点、字幕冲击。
3. **界面实录 / 产品巡礼**：真实 UI 4K 截图、推镜、标注。
4. **手绘白板讲解**：纸面、线条、圈注、旁白驱动。
5. **Q 版卡通 / 吉祥物**：角色、明亮色彩、轻松节奏。
6. **赛博朋克霓虹**：暗底、霓虹、故障感、科技产品。
7. **瑞士平面 / 杂志排版**：网格、大字、色块、信息图。
8. **国潮 / 水墨**：留白、墨色、东方质感、文化产品。

## 选择规则

- 先判断产品气质，再给 3–4 个差异明显的方向；
- 每个方向出 1 张 16:9 样帧；
- 至少一个“意想不到”的方向；
- 用户选一个后才进入 CreativePackage production；
- 不照搬其他产品的配色和版式。

## 叙事结构

- 痛点 → 产品 → 证据 → CTA
- 一句话定位 → 3 个卖点 → 数字证明 → CTA
- 前后对比 → 机制 → 结果 → CTA
- 电影预告：悬念 → 揭示 → 能力 → 高潮 → CTA
