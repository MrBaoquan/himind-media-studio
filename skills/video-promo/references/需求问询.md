# 产品宣传片需求问询

## 第一轮：定方向

1. 产品是什么？官网/仓库/本地目录在哪？
2. 目标用户是谁？看完希望他们做什么？
3. 核心卖点/痛点是什么？有没有可证明的数字、案例、客户？
4. 时长与画幅：默认 45–60 秒、16:9；抖音/视频号可 9:16。
5. 风格方向：给 3–4 个差异明显的方向，每个出一张样帧。
6. 叙事结构：痛点开场 / 数字冲击 / 产品巡礼 / 前后对比 / 电影预告。
7. 真实素材：官网截图、产品界面、演示视频、客户 logo、仓库 README。
8. 声音方案：AI 旁白 + BGM / 大字幕 + BGM；音色稍后试听。
9. 版权边界：哪些素材可用、是否需要标注来源、是否可商用。
10. CTA：产品名/网址/二维码/行动指令；没有真实链接时不要编造。

## 第二轮：定细节

- 开场 3 秒钩子；
- 3–5 个功能段落；
- 每个段落的真实素材与一句话说明；
- 高潮镜头/数据证明；
- CTA 位置与时长；
- 导出规格（1080p/4K、横/竖、fps）。
