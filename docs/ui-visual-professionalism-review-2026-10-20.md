# 自媒体创作台：UI 专业度与视觉协调审查（2026-10-20）

> 纯真实页面视角：1440×900 浅色/深色、关键局部 2× 放大、100 镜头压力页、五轨剪辑台。
> 不看代码结构，只评价用户看到的层级、排版、色彩、密度、平衡与一致性。
> 版本：`com.himind.media-workbench@0.74.1`

## 一、结论

功能密度已经达到专业工具水平，但**视觉语言仍偏“内部数据工具”**，不是成熟 creative product。

| 表面 | 视觉评分 |
| --- | --- |
| 深色剪辑工作台 | 78 |
| 浅色剪辑工作台 | 66 |
| 审阅页 | 62 |
| 计划页 | 60 |
| 分镜编辑器 | 61 |
| 创作脉络 | 64 |
| 跨页面一致性 | 55 |
| **整体视觉专业度** | **63/100** |

对标：Resolve 约 88，CapCut 约 84，Premiere 约 82。
差距不在功能，而在**排版尺度、信息分级、表面一致性、空态/错误态和品牌感**。

## 二、真实页面数据

在审阅页 1440×900 实测：

- 225 个可见文本叶节点；
- 92 个可见按钮；
- 81% 文本 ≤10.5px，37% ≤9.5px；
- 最大正文只有 12.5px；
- 5 个“主按钮”级蓝色 CTA：生成审查图、重新生成、打开最新成片、检查确定性并渲染、记录反馈；
- 二级文字色 `#8b909b` 对白底对比度 **3.20:1**；
- 深色二级文字 `#6c6f7d` 对 `#0a1220` 对比度 **3.76:1**；
- 圆角混用 8/7/6/5px；
- 按钮高度混用 28/27/20px。

这些数字与肉眼感受一致：**小、灰、密、主次不清**。

## 三、逐屏视觉判断

### 3.1 全局壳与双层头部

审阅/计划/分镜页有两层头部：

1. 全局头：Logo、工作区路径、创意 chip、刷新/新建/风格库/创作脉络/生成审查图/引导；
2. 项目头：审阅/分镜/剪辑 tabs + 项目名/类型/风格/修订 + 视图动作。

问题：
- 两层头部都是浅色/深色同底，只靠 1px 线分隔，层级弱；
- 全局头 7 个动作 + 主题切换，太满；
- tabs 与项目名不在同一基线，项目头显得高而散；
- “生成审查图”和“重新生成”两个蓝色主按钮同屏竞争。

**方向**：全局头只保留工作区/创意/设置；项目级动作全部下沉到项目头；一个屏幕只保留一个主 CTA。

### 3.2 审阅页

优点：三栏结构清楚，审查图是视觉中心，QA 信息完整。

问题：
- 黑色舞台占 70% 宽度，画面只占中间 266px，形成巨大黑色空洞；
- 审查产物列表只有文字和大小，没有缩略图，像文件列表而不是 visual review；
- 右栏是“代码项目”技术表：源码目录、入口、渲染器、创意 ID、时间戳、check id 全部暴露；
- 体检报告 10+ 行，每行都是绿色勾 + 小字，视觉噪声大，真正的异常（skipped）反而不突出；
- 反馈输入框很大，但“动效/记录反馈”缩在右上，主次倒置；
- 底部 72s 时间条太薄，像占位符。

**方向**：
- 右栏改为“创作状态”优先：预览/确定性/产物/时长四块摘要，技术信息折叠到“技术详情”；
- 体检报告默认只显示 3 条摘要 + “查看全部”；
- 审查产物改为缩略图网格；
- 反馈区改成固定底部操作条：输入 + 发送给 AI（主按钮）+ 类型；
- 舞台改为中性深灰/棋盘格，减少黑块压迫。

### 3.3 计划页（100 镜头）

问题：
- 右侧质量门禁 67 项直接铺开，红黄徽章 + 长列表抢占注意力；
- 左侧 100 个镜头没有缩略图、没有搜索、没有分组，纯文字列表；
- 每个镜头都是同样的小卡片，节奏单调；
- 主 CTA 是“生成动效预览”，但页面本身是只读计划，用户不知道能否先改计划。

**方向**：计划页应是“可扫描的叙事板”：镜头缩略图/类型色块/时长条；门禁摘要化；主 CTA 改为“继续制作”或“让 AI 调整计划”。

### 3.4 分镜编辑器（100 镜头）

问题：
- 左列表每行塞入 checkbox、序号、标题、类型、时长、上下箭头、锁、复制，控制条过密；
- 右侧是标准后台表单，字段全宽，缺少“镜头预览”；
- 没有视觉节奏：100 个镜头看起来像 100 行数据库记录；
- “保存并预览”是唯一亮色按钮，但离编辑器主体较远。

**方向**：
- 左列表加缩略图/类型色条，箭头/锁/复制收进 hover 菜单；
- 右侧顶部加镜头预览卡（模板缩略图/关键帧）；
- 字段分组为“内容 / 视觉 / 数据 / 来源”；
- 增加“AI 修改此镜头”作为局部主 CTA。

### 3.5 创作脉络

问题：
- 整体像后台表单，不像创作空间；
- 中间 Brief 表单字段全宽、字号小，留白多但信息弱；
- 左侧 7 步 stepper 清楚，但“下一步”没有单一 CTA；
- 右下“校验/批准/创建”三个动作并列，主次不清；
- 左下“交给 AI”被压成小面板，架构说明文字 9px，几乎不可读；
- 全页没有一个视频/分镜预览，创作感弱。

**方向**：
- stepper 上提供唯一“下一步”按钮；
- “交给 AI”改为固定底部操作条；
- 右栏摘要化，技术能力 ID 折叠；
- 增加一个轻量预览/情绪板区域。

### 3.6 剪辑工作台

深色版明显优于浅色版：
- 深色下时间线、轨道、clip、监视器形成统一暗色工作区，专业感强；
- 浅色下大量白色 lane + 浅灰边框，显得像线框图/原型；
- 单轨项目下方大面积黑色空洞；
- 空源监视器占 50% viewer 宽度；
- 未选片段时右侧 Inspector 空占 310px；
- 75 个按钮，工具条像功能清单而不是任务导向工具栏。

**方向**：
- 编辑态默认深色，或把浅色调成有层次的“纸面剪辑”主题；
- 空 Inspector 自动折叠；
- 源监视器在无选中时折叠/显示最近素材；
- 时间线空区提供“添加轨道/拖入素材”引导；
- 工具条按“剪辑/音频/字幕/交付”分组，低频动作进“更多”。

## 四、跨页面一致性问题

| 问题 | 表现 |
| --- | --- |
| 头部模型不一致 | 审阅/计划/分镜是双层头；创作脉络是单层头；剪辑是全局头+编辑器头 |
| 面板语法不一致 | 审阅右栏是无卡片表格；创作脉络右栏是圆角卡片；分镜右栏是表单 |
| 按钮语法不一致 | pill tabs、outline buttons、icon buttons、蓝色主按钮混用 |
| 字体尺度不一致 | 8.5/9/9.5/10/10.5/11/11.5/12/12.5/13px 十档 |
| 圆角不一致 | 5/6/7/8px 混用 |
| 主题不一致 | 深色编辑台专业，浅色编辑台像原型；其他页面浅色更常见 |

## 五、设计系统建议

### 5.1 排版

- 正文基准 12.5–13px，元数据最低 11px；
- 禁止 8.5/9px 作为可读正文；
- 标题层级：28 / 20 / 16 / 13 / 11；
- 中文字体优先系统 UI 字体，英文/数字可用等宽但只用于 ID/时间码。

### 5.2 对比度

- 浅色二级文字从 `#8b909b` 提升到 `#5e6471`（对比度约 5.6:1）；
- 深色二级文字从 `#6c6f7d` 提升到 `#9a9ca8`（对 `#0a1220` 约 6.5:1）；
- 状态色只用于状态，不用于正文。

### 5.3 主次

- 每屏一个主按钮；
- 次要动作 outline/ghost；
- 危险动作红色仅用于确认层，不常驻；
- “生成/预览/导出/交付”四个词固定语义，不再混用。

### 5.4 表面与层级

- 统一 4/8px 间距系统；
- 圆角统一 6/8/10px 三档；
- 卡片使用 1px 边框 + 极轻阴影，避免纯白贴纯白；
- 技术元数据统一折叠到“技术详情”。

### 5.5 空态/错误态

- 空 Inspector 自动折叠或显示快捷动作；
- 空源监视器显示最近素材/拖入提示；
- 渲染失败显示预检面板，不只 toast；
- 插件宿主 502 显示错误页 + 重试，不白屏。

## 六、优先级

### P0：先统一视觉语法

1. 一套排版尺度（12.5/11 最低）；
2. 一套按钮体系（主/次/幽灵/危险，3 个高度）；
3. 一套圆角/间距/边框规则；
4. 一个屏幕一个主 CTA；
5. 技术元数据折叠。

### P1：逐屏打磨

6. 审阅页：缩略图网格 + QA 摘要 + 反馈底栏；
7. 计划页：镜头缩略图/色块 + 门禁摘要；
8. 分镜页：镜头预览卡 + hover 控制条；
9. 创作脉络：stepper 单一 CTA + 固定 AI 操作条；
10. 剪辑页：浅色主题重做、空 Inspector 折叠、空时间线引导。

### P2：品牌感

11. 统一插画/图标风格；
12. 统一状态色与数据可视化色板；
13. 加入适度的品牌强调色与表面层次；
14. 动效只用于状态变化，不做装饰性动画。

## 八、判断

**功能已经像专业工具，视觉还像内部系统。**

最有效的提升不是“再加颜色/阴影”，而是：
1. 把字号和对比度拉到可舒适阅读；
2. 把 92 个按钮收敛成任务导向的工具组；
3. 把技术元数据从主界面移走；
4. 让审阅/计划/分镜/创作脉络共享同一套头部、卡片、按钮和空态；
5. 让深色剪辑台成为视觉基准，浅色主题按同一层次重做。

做到这五点，视觉专业度可以从 63 提升到 80+，而不需要改变现有功能架构。
