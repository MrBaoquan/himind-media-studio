# 剪映式易用性 + 达芬奇式精修：融合方案

> 日期：2026-10-19
> 定位：**一键成片是入口，精修是退路。** 两套体验共用同一 Timeline 与命令总线，不做第二套剪辑内核。

## 一、融合原则

| 原则 | 说明 |
| --- | --- |
| 同一时间轴 | 简易模式与专业模式操作同一份 Timeline |
| 简易动作 = 命令宏 | “一键字幕/智能剪辑/卡点”最终都落到 insert/trim/blade/transition 等核心命令 |
| 先预览再提交 | 所有智能操作先生成 diff 预览，可撤销 |
| 渐进披露 | 默认只露出 5–7 个动作，专业能力按需展开 |
| 模板即资产 | 文字、转场、特效、音乐、导出预设都做成 Asset Pack，不做死在代码里 |

## 二、双层体验

```text
简易模式（默认）
  一键成片 / 自动字幕 / 智能剪辑 / 卡点 / 自动重构 / 导出预设
        ↓ 随时“精修”
专业模式（可选）
  媒体池 / 双监视器 / 多轨 / Blade / Ripple / Trim / Inspector
```

切换不丢状态；专业模式的修改会同步回简易模式的时间轴。

## 三、简易模式的信息架构

```text
Topbar：项目 · 一键成片 · 自动字幕 · 卡点 · 精修 · 导出
Left：素材托盘（视频/图片/音乐/文字/贴纸）
Center：预览画布（竖屏/横屏切换）
Right：智能面板（字幕样式 / 转场 / 音乐 / 导出）
Bottom：简化时间轴（主轨 + 音频 + 字幕）
```

关键：简易模式不显示 V2/A2/轨道目标/Trim 模式，只保留“拖入、分割、删除、排序、时长”。

## 四、智能操作（Easy Actions）

| 动作 | 输入 | 输出 | 可撤销 |
| --- | --- | --- | --- |
| 一键成片 | 素材 + 音乐 + 时长 | 初始 Timeline + 转场 + 字幕 | 是 |
| 自动字幕 | 旁白/音频 | 字幕轨 + 样式 | 是 |
| 智能剪辑 | 长视频 | 去静音/去停顿/按场景切分 | 是 |
| 卡点 | 音乐 + 素材 | 按节拍切分与转场 | 是 |
| 自动重构 | 横屏素材 | 9:16 主体跟随 + 安全区 | 是 |
| 自动压低 | 旁白 + BGM | ducking 区间 | 是 |
| 高光提取 | 长素材 | 候选片段列表 | 是 |

实现方式：每个动作是一个“宏”，内部调用核心命令；输出包含 `diff` 与 `preview`，用户确认后才提交 revision。

## 五、模板与“剪同款”

模板不是视频文件，而是带槽位的时间轴：

```json
{
  "template_id": "travel-vlog-9x16",
  "slots": [
    {"id": "media", "type": "video", "count": 6, "duration": "2-4s"},
    {"id": "title", "type": "text", "max_chars": 12},
    {"id": "music", "type": "audio", "beat_sync": true}
  ],
  "timeline": "..."
}
```

用户只需替换槽位；AI 可自动填充并做时长适配。模板作为 Asset Pack 分发，可版本化、可授权。

## 六、预设资产化

| 类型 | 形态 | 例子 |
| --- | --- | --- |
| 字幕样式 | Asset Pack（字体/描边/动画） | 手绘、综艺、极简 |
| 转场 | Asset Pack（参数模板） | 叠化、擦除、闪白 |
| 文字动画 | Asset Pack | 打字机、弹跳、逐字 |
| 音乐/音效 | Asset Pack（license） | BGM、whoosh、click |
| 导出预设 | Asset Pack（平台规范） | 抖音 1080×1920 / B站 16:9 |

## 七、简易 → 专业的交接

- “精修”按钮把当前 Timeline 带入专业模式；
- 专业模式显示“来自简易操作”的标记；
- 返回简易模式时保留精修结果；
- 任何智能动作都记录为可回放的命令序列。

## 八、实施阶段

### C-01 简易模式壳（P0）

- 素材托盘 + 预览 + 简化时间轴；
- 一键成片 / 自动字幕 / 智能剪辑入口；
- 与专业模式共用 Timeline。

### C-02 智能操作（P0）

- 自动字幕（复用 audio.align）；
- 去静音/场景切分（复用 visual.video.scenes）；
- 卡点（节拍检测 + blade 宏）。

### C-03 自动重构（P1）

- 9:16 / 1:1 / 16:9；
- 主体跟随与安全区；
- 输出 transform 命令。

### C-04 模板槽位（P1）

- 模板 Asset Pack；
- 槽位替换与时长适配；
- “剪同款”。

### C-05 预设资产（P1）

- 字幕样式、转场、文字动画、音乐、导出预设；
- 版本与 license。

### C-06 简易↔专业（P0）

- 精修入口与返回；
- 操作标记与命令回放。

### C-07 导出预设（P1）

- 抖音/B站/YouTube；
- 画幅、码率、响度、字幕烧录。

## 九、验收

- 新用户 3 分钟内用“一键成片”得到第一版；
- 自动字幕与卡点结果可预览、可撤销；
- 简易模式的所有操作都能在专业模式看到对应命令；
- 模板替换 6 段素材后时长自动适配；
- 导出预设一次通过平台规范。

## 十、非目标

- 不复制剪映全部贴纸/特效库；
- 不做移动端优先的复杂手势；
- 不把简易模式做成“黑盒”：每个动作都要可解释、可回退。
