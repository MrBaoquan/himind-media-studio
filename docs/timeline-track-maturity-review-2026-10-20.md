# 时间线 / 轨道设计成熟度审查（2026-10-20）

> 审查对象：`com.himind.media-workbench@0.70.4`
> 审查方式：18082 真实页面 + 5 轨实验时间线 + CDP 几何/交互测量
> 对标：DaVinci Resolve（结构纪律）、Premiere Pro（轨道操作）、CapCut（易用性）

## 一、结论

时间线已经从“能放 clip 的列表”进入 **可用的专业剪辑骨架**：

- 轨道头可操作，不再是只读装饰；
- 轨道可增删，视频轨隐藏会影响节目监视器与渲染主轨选择；
- 1440×900 下 5 轨首屏完整可见；
- 800×600 低高度窗口进入紧凑模式，时间线优先；
- 播放头跨项目不再串帧。

但距离 Resolve/Premiere 的成熟度仍有明显差距。当前综合评分约 **75/100**，属于“可日常使用、可 AI 驱动生产”，还不是“专业剪辑师可完全替代”的形态。

## 四、本轮实际改造（0.70.0 → 0.70.4）

### 4.1 轨道头

- gutter 96px → 128px，clip 起点与标尺重新对齐；
- 轨道头改为横向布局：色条 + 名称 + 类型/角色 + 操作按钮；
- 视频轨显示 Eye/EyeOff，音频轨显示 Volume2/VolumeX，所有轨道有 Lock/Unlock；
- muted 轨道名称删除线、lane 降透明度；
- 右键轨道头：隐藏/静音、锁定、插入素材、删除空轨道；
- TRACKS 标题旁新增 `+`，可添加视频/音频/字幕轨。

### 4.2 轨道命令

新增后端命令：

- `add_track`：按类型插入到同类型最后一条之后，自动编号；
- `remove_track`：只允许删除空轨道，禁止删除最后一条轨道；
- `set_track_state`：muted / locked / role。

新增 Go 测试：

- 轨道排序与自动编号；
- 锁定/解锁与空轨道删除；
- 非空/最后轨道拒绝删除；
- muted 视频轨被跳过，主轨选择回退到下一视频轨。

### 4.3 视频轨隐藏语义

- `ProgramMonitor` 跳过 muted 视频轨；
- 渲染主轨选择跳过 muted 轨；
- overlay 轨道跳过 muted 轨。

这意味着 M 按钮不是装饰：它同时影响预览与导出。

### 4.4 播放头正确性

- 项目切换时 `playhead=0`，清空选择与播放状态；
- timeline 变化时 clamp 到 `duration_frames - 1`；
- ProgramMonitor 显示与 scrub 使用 safePlayhead。

修复了从 9030 帧项目切到 600 帧项目仍显示 `f5000` 的真实串帧问题。

### 4.5 视觉与窄屏

- 行高 54/48/42，5 轨 + 标尺 = 312px，1440×900 首屏完整；
- 标尺改为 `0:00 / 0:02 …` 的 mm:ss 标签；
- 字幕 clip 以字幕文本为主标签，避免文本与 id 重叠；
- `max-height: 720px` 进入紧凑模式：隐藏源监视器、压缩节目监视器、时间线最小 170px。

## 七、与成熟产品的差距

### P0：影响专业操作

1. **逐轨高度调整**：目前只有固定 54/48/42，缺少拖拽轨底或紧凑/标准/高预设。
2. **Solo**：没有 solo 按钮；多音轨时无法快速独听。
3. **轨道排序/重命名/自定义颜色**：轨道顺序由类型决定，不能拖拽调整。
4. **音频表与音量**：轨道头没有实时电平、dB 数值或音量滑杆。
5. **clip 悬停 scrub / 源监视器单双切换**：窄屏只能整体隐藏源监视器。
6. **marker lane / mini-map**：模型有 markers，但时间轴没有独立标记 lane 和全局缩略图。

### P1：影响效率

7. 转场只能从 clip 角手柄拖，不能从素材面板或 clip 间隙拖入。
8. 波形缺少 dB 刻度和纵向缩放。
9. 多选/框选已有代码，但需要专项 e2e 与批量操作可视化。
10. 横向滚动条/更多工具菜单的可发现性不足。

## 八、判断

**可以继续以这条时间线为底座做 AI 自媒体创作，不需要换 Timeline 内核。**

但下一阶段应优先补“轨道操作深度”（逐轨高度、solo、排序、音频表），而不是继续堆更多按钮。成熟产品的差距不在功能数量，而在轨道级控制、反馈清晰度和高频操作的顺手程度。
