## 一、它到底是什么

这不是“完整官方线网图”，也不是“3D 城市地图”。

它是一条**开通事件时间轴**：

```text
地图作为背景
+ 线路按开通顺序逐条生长
+ 底部卡片同步显示日期 / 区段 / 累计里程
+ 所有事件都落在 12 月 26 日
→ 形成“合肥轨道交通对 12/26 情有独钟”的记忆点
```

核心不是“地图有多复杂”，而是：

```text
时间 → 线路 → 区段 → 里程
```

四个变量同步变化。

## 四、单个事件的运动语法

```text
0.0–0.2s   底部卡片上滑进入
0.0–2.8s   新线从起点画到终点（白色描边 + 彩色主线）
0.6–3.2s   站点按沿线距离依次弹出
0.0–3.8s   累计里程从上一条线的值滚动到新值
1.0–3.0s   镜头推近新线包围盒，保持轻推
2.8–5.4s   当前线路站名出现，换乘站脉冲
3.0–5.4s   列车点沿线移动
5.4–6.2s   卡片下移退出，进入下一事件
```

关键判断：

- 线路不是一次性全部出现，而是“当前事件一条、历史线路变淡”；
- 站名不是逐帧重排，而是固定布局；
- 里程数字是连续的“里程表”动画，不是直接跳变；
- 日期卡片是主叙事载体，地图只是证据。

## 五、在本项目中的实现

新增 Style Pack：

```text
style-packs/transit-opening-timeline/
```

规格：

```text
1080×1920 / 30fps / 38s / browser-code / Canvas 2D
```

时间轴：

```text
0–3.6s      标题 + 淡线网
3.6–9.8s    2016 / 1 号线
9.8–16.0s   2017 / 2 号线
16.0–22.2s  2019 / 3 号线
22.2–28.4s  2021 / 4 号线
28.4–34.6s  2022 / 5 号线
34.6–38s    全网友好视图 + 统计
```

实现要点：

- 暖白点阵背景；
- 当前线路彩色 + 白色描边 + 轻 glow；
- 历史线路 34% 不透明度；
- 底部卡片：日期、线路色块、区段、累计里程、12/26 徽标、年份轨道；
- 里程使用等宽字体 + `easeOutExpo` 滚动；
- 镜头按当前线路包围盒推近/拉回；
- 标签沿用固定布局，不做逐帧重排。

## 六、与参考的差异

| 维度 | 参考视频 | 当前实现 |
| --- | --- | --- |
| 时长 | 4:03 | 38s（短视频版） |
| 数据 | 真实事件链（含 5 号线等） | 5 条线示意子集 |
| 地图 | 专用线网布局 | 现有 `transit-network` 示意几何 |
| 里程 | 官方运营里程 | 演示值（24.6 / 52.4 / 89.6 / 131.0 / 171.2） |
| 音效 | 原视频音乐/音效 | 程序化环境声床 |
| 版式 | 参考作者版式 | 原创信息卡片版式 |

当前版本的目标是**复刻运动语法和信息层级**，不是复制原片。
