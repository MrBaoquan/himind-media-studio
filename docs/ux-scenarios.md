# 创作台场景化 UX 改进清单

> 日期：2026-10-19
> 目标：从“功能可用”提升到“真实创作旅程顺畅”。
> 方法：按用户任务而不是按页面拆分；每个场景给出当前断点、改进项与验收标准。

## 一、场景总览

| ID | 场景 | 用户目标 | 当前断点 | 优先级 |
| --- | --- | --- | --- | --- |
| S1 | 首次进入 | 5 分钟内做出第一版 | 空工作区只有文字提示 | P0 |
| S2 | AI 对话到第一版 | 一句话 → 可审阅项目 | AI 任务在创作台不可见 | P0 |
| S3 | 创意包 → 项目 | 确认改动并物化 | 血缘与差异不可见 | P0 |
| S4 | 分镜打磨 | 快速改大量镜头 | 镜头多时难定位、无批量操作 | P0 |

## 二、关键场景细化

### S1 首次进入

当前：绑定工作区后只看到“还没有项目 / 用新建项目开始”。

改进：

1. 三步引导：绑定工作区 → 选择起点（描述主题 / 模板 / 导入创意包）→ 生成第一版；
2. 内置 1 个可运行的示例项目（含预览、分镜、QA 报告）；
3. 记住最近工作区与最近项目，二次进入直接恢复上次位置；
4. 空态提供两个明确动作：“描述一个主题”“从模板开始”。

验收：新用户不读文档，5 分钟内能得到一个可预览项目。

### S2 AI 对话到第一版

当前：AI 在客户端对话，创作台只能看到结果；复制提示词是手工动作。

改进：

1. 顶栏“AI 任务”状态：进行中 / 待确认 / 已完成 / 失败；
2. 任务卡片显示：目标、当前步骤（脚本/分镜/生成/QA）、耗时；
3. “在 AI 中继续”深链，带回当前创作包与选中镜头上下文；
4. AI 完成后创作台自动刷新（已有），并高亮变更内容；
5. “采纳为创意包”一键动作，避免手工搬结果。

验收：用户从 AI 对话回来，无需寻找，能直接看到这次改了什么。

### S3 创意包 → 项目

当前：materialize 后关系只存在数据里。

改进：

1. 常驻血缘：`creative@r3 → project`；
2. 物化前显示差异摘要：Brief / 脚本 / 分镜 / 制作规格各自变化；
3. “重新物化”给出影响预览：会覆盖哪些镜头、是否丢失手工修改；
4. 已物化项目显示“来源创意包”入口。

验收：任何时候都能回答“这个项目来自哪版创意包、改了什么”。

### S4 分镜打磨

当前：镜头多时是长列表；两套分镜实现；无时间轴联动。

改进：

1. 镜头列表虚拟化 + 按场景分组 + 折叠；
2. 多选与批量：改时长、换风格、重新生成、锁定；
3. “锁定镜头”防止 AI 后续覆盖；
4. 键盘：↑/↓ 切换镜头，Space 播放，Enter 编辑；
5. 与时间轴双向联动：选中镜头 → 时间轴定位；拖动时间轴 → 镜头高亮；
6. 统一分镜组件，代码项目与模板项目同一套交互。

验收：100 个镜头时仍能快速定位与批量修改，不出现长列表卡顿。

### S5 反馈迭代

当前：feedback.record 有数据，但用户看不到“反馈 → 变更”的闭环。

改进：

1. 反馈收件箱：open / applied / rejected，可按镜头过滤；
2. AI 修改后生成“变更摘要”：改了哪些镜头、哪些字段；
3. 版本对比与一键恢复；
4. 支持“只改第 3 镜”这类范围化反馈。

验收：每条反馈都能追踪到是否被采纳、落在哪个 revision。

### S6 音频/字幕

当前：能生成旁白与对齐字幕，但缺少逐句编辑与波形。

改进：

1. 字幕轨 + 波形 + 旁白区间可视化；
2. 逐句编辑：文本、起止时间、说话人；
3. 同步告警：漂移 > 0.2s 时高亮并可一键重建；
4. BGM ducking 的可视化区间；
5. 试听当前镜头 / 当前句。

验收：不改代码即可完成字幕修正与音画对位。

### S7 审阅与 QA

当前：QA 结果以 code、JSON、状态为主。

改进：

1. “体检报告”面板：按严重度分组，显示时间点、截图、修复建议；
2. 点击问题跳转到对应镜头/时间；
3. 一键导出失败帧/联系表；
4. 区分 blocker / warning / 待复核，避免“全红”；
5. 报告可作为产物分享。

验收：非技术用户能看懂“哪里错、为什么、怎么修”。

### S8 长任务等待

当前：状态栏显示 job，用户离开后无提醒。

改进：

1. 任务中心：进行中 / 完成 / 失败，含 ETA；
2. 完成或失败时桌面通知；
3. 重新打开创作台自动恢复任务状态；
4. 失败任务保留日志入口。

验收：用户离开 10 分钟回来，能立刻知道结果与下一步。

### S9 失败恢复

当前：错误以文本展示，缺少重试上下文。

改进：

1. 错误卡片：原因 / 影响 / 修复动作 / 重试；
2. 自动保存草稿与恢复提示；
3. 渲染失败保留已完成帧与断点；
4. 常见错误提供“一键修复”（如 audio_path、缺失参考包）。

验收：失败后不丢稿，80% 常见错误可一键恢复。

### S10 素材复用

改进：

1. 资产浏览器支持拖拽到镜头；
2. 参考包显示许可证/商用标记与一致性状态；
3. “套用到选中镜头”与“套用到全片”；
4. 最近使用与收藏。

### S11 系列/批量

改进：

1. 系列向导：数据表 → 模板 → 批量预览 → 逐条确认；
2. 每条状态独立，可部分重试；
3. 批量产物打包导出。

### S12 AI/人工交接

改进：

1. “当前任务”卡片：谁在处理、下一步是什么；
2. 交接摘要：本次目标、已改内容、待确认项；
3. 深链：AI 客户端 ↔ 创作台保持同一 creative/project 上下文；
4. 评论/批注可定位到镜头或时间点。

## 三、跨场景体验基线

- 自动保存 + 崩溃恢复；
- 全局撤销/重做；
- 命令面板与快捷键；
- 统一 empty / loading / error / blocked 状态；
- 大项目虚拟化与渐进加载；
- 所有长任务可取消、可重试、可恢复；
- 键盘可达与 focus ring；
- 浅色/深色一致的信息层级。

## 四、优先级建议

### P0（先做，直接决定“能不能用顺”）

1. S2 AI 任务可见性；
2. S3 创作包→项目血缘与差异；
3. S4 大量镜头可用性（虚拟化/批量/锁定/键盘）；
4. S7 QA 报告可读性与跳转。

### P1

5. S5 反馈闭环；
6. S6 字幕轨与波形；
7. S8 任务通知；
8. S9 失败恢复；
9. S12 交接摘要。

### P2

10. S10 素材拖拽；
11. S11 系列/批量；
12. 引导与渐进披露。

## 五、验收方式

每个场景用一条真实任务走查，而不是只看页面：

- S2：从一句主题到可审阅项目；
- S4：100 镜头项目中定位并批量修改 5 个镜头；
- S7：制造一次字幕重叠与一次色带告警，确认可定位可修复；
- S8：启动渲染后离开，回来看到通知与结果；
- S9：断开音频路径触发失败，确认可一键恢复。
