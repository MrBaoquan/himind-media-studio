# 案例：HiMind 产品宣传片

## 需求
- 产品：HiMind Agent + 自媒体创作台
- 目标：用真实产品界面和克制叙事，展示 AI 如何把一句话推进到可审阅、可修改、可交付的成片
- 规格：16:9 / 1920×1080 / 30fps / 35 秒

## 方向
- 默认风格：电影深色 · 青绿（cinema-teal / promo-cinema）
- 备选：杂志编辑暖白、瑞士网格信号红、科幻信号电光蓝
- 叙事：定位 → 创作脉络 → 多轨时间线 → 审阅与质量 → CTA

## 真实素材
- 创作脉络 3840×2160 真实界面图
- 五轨时间线 3840×2160 真实界面图
- 审阅/反馈/QA 3840×2160 真实界面图
- 原图位于项目 `capture-4k/`，运行时副本位于插件的 `renderer/remotion/public/promo/`

## 生产结果
- 模板：`promo-video@1.0.0`
- Composition：`PromoVideo`
- 时长：35.000 s / 1050 帧
- 视频：H.264 1920×1080 30fps
- 音频：AAC 48kHz 双声道，I=-15.9 LUFS，true peak=-1.7 dBFS
- 字幕：烧录；9 条 cue 与旁白同源
- 质量：0 个黑帧区间、无 ≥1.5s 静帧、色带检查通过
- 确定性：150/525/900 三帧两轮 SHA 完全一致
- 项目闭环：反馈记录、项目 revision 2→3、最终 artifact 保留、时间线已保存 revision 1

## 本轮踩坑
- 插件打包误收 `.cache/webpack`，包体膨胀并导致候选解包失败。
- Remotion CLI 在 stdin=NUL 时会报 `write EOF`；worker 必须提供保持打开的 stdin 管道。
- Chrome 临时目录不可写时 `mkdtemp` 报 EPERM；worker 应把 TEMP/TMP 定向到工作区内。
- 截图场景缩放后，标题栏上边距曾到 94.65px；96px 安全区必须用真实 DOM 包围盒复验，不能只靠视觉估计。

## 可复用规则
1. 先确认事实和真实素材，再讨论风格。
2. 所有静态图至少 1920×1080，产品界面优先 1920×1080@2x 捕获。
3. 风格必须出 3–4 张同规格样帧，再选主方向。
4. 文字安全区用真实 DOM 包围盒复验。
5. 成片必须通过规格、响度、黑帧/静帧、色带和确定性三帧 Hash。
6. 成片必须进入项目产物，并把反馈、新 revision、时间线保存串成闭环。
