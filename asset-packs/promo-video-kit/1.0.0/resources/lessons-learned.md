# 产品宣传片踩坑记录

1. **Remotion public 静态路径不稳定**：改用内置 data URL 资产，避免 404 与渲染中断。
2. **场景边界空白帧**：顺序场景在边界同时透明度归零；用 8 帧交叉重叠。
3. **子场景用全局帧**：入场动画不触发；用 Sequence 局部帧。
4. **虚构 CTA/网址**：没有真实链接时只写产品名/体验入口，不编造域名。
5. **真实截图带私人路径/Token**：截图前替换工作区标签、隐藏敏感信息。
6. **把 AI 示意图当真实产品图**：必须标注“示意图”。
7. **宣传未上线能力**：只写已实现、可演示的能力。
8. **音频无许可证**：BGM/音色必须记录来源与商用边界。
9. **画面文字太多**：每屏只讲一件事，重点镜头至少 1.3 秒。
10. **只交预览不交 MP4**：验收以真实 artifact 为准。
11. **Remotion 授权**：3 人以上公司商用需确认 Remotion 商业授权。
12. **字幕与旁白不同源**：script.beats[].narration 作为唯一文本源。

13. **插件载荷误收缓存**：发布前排除 `.cache`、`dist`、`node_modules`，否则 Remotion/Webpack 缓存会让包体从数十 MB 膨胀到数百 MB。
14. **Remotion worker stdin=NUL**：整片渲染会报 `write EOF`；为 Node 子进程提供保持打开的匿名 stdin 管道，命令结束后再关闭。
15. **Chrome 临时目录 EPERM**：Remotion worker 要把 `TEMP`/`TMP` 指向工作区内可写目录，不能假设系统 Temp 对后台进程可写。
16. **截图场景缩放漂移**：容器 `scale()` 会把顶部标题栏推入安全区；用真实 Player DOM 包围盒在多个时间点复验，发现后把截图框 `top` 从 120 调到 130。
17. **4K 素材不是放大图**：用 WebView2/CDP 以 1920×1080 CSS viewport、2× device scale 捕获 3840×2160，保留产品界面文字与布局。
18. **只保存时间线不保存修订不够**：最终交付必须同时保留 artifact、反馈、项目 revision 与时间线 revision，并在重启后复核。
