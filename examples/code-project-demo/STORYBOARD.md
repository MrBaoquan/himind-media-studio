# 动态字体 Mini

这是 HiMind Browser-Code 项目模式的最小黄金样例。

## 时间预算

| 时间 | 镜头 | 观众要读到什么 |
| --- | --- | --- |
| 0–2s | 标题入场 | AI 能力沉淀，不是一次性视频 |
| 2–5s | 三项能力卡 | Shot / Technique / Contract 是可复用资产 |
| 5–8s | 流向与节奏 | 需求、计划、预览、反馈形成闭环 |
| 8–10s | 收束 | READY TO ITERATE |

## 事实与示意

- 本样例是方法演示，不包含真实业务数据。
- 画面中的数字均为 SCHEMATIC。
