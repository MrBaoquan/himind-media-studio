# 线网地图动画 · Transit Network

> 30 秒竖屏 / 1080×1920 / 30fps / 白底官方线网图风格。  
> 数据为示意子集，不是完整线网，不用于出行。

## 叙事

| 时间 | 画面 | 观众必须读到 |
| --- | --- | --- |
| 0–0.8s | 白纸、标题、南淝河淡入 | 合肥地铁线网 |
| 0.8–7.4s | 1→2→3→4→5 号线依次生长，站点与站名出现 | 线网在时间中生长 |
| 7.4–10.5s | 图例展开，列车点开始沿线移动 | 站点、线路、换乘 |
| 10.5–16.5s | 换乘节点脉冲，镜头轻推 | 换乘让网络连起来 |
| 13.5–20.5s | 年份轴 2016→2025，图例逐条高亮 | 线网生长的时间尺度 |
| 22–30s | 镜头拉回，结论 | 轨道上的合肥 |

## 数据契约

读取 `input/data.json`：

```json
{
  "title": "合肥地铁",
  "subtitle": "轨道上的城市生长",
  "as_of": "2025-12",
  "source": "示意线网 · 仅展示部分线路与站点",
  "disclaimer": "示意图，非完整线网，不用于出行",
  "lines": [
    {"id":"L1","name":"1号线","color":"#E60012","opened":2016,"path":[[300,420],[300,600],[480,780]],"stations":["hfhcz","ddd"]}
  ],
  "stations": [
    {"id":"ddd","name":"大东门","x":480,"y":780}
  ]
}
```

## 站名避让规则

- 8 方向候选位；
- 换乘站优先级最高，其次终点站，最后普通站；
- 标签不得越出安全区；
- 标签不得互相重叠；
- 标签不得压站名点；
- 第一轮不允许压线；换乘站允许带引线的第二轮回退；
- 所有站名位置在整段动画中保持稳定，不做逐帧重排。

## 数据边界

- 内置数据为**示意子集**，线路名和站名用于视觉演示；
- 正式发布前必须替换为官方线网 / OSM / GTFS 校验过的数据；
- 画面必须保留来源、截止日期和“示意图”声明；
- 不直接使用第三方地图截图。

## 渲染

```bash
npm install
node render.mjs --stills=1,5,9,13,18,24,28 --out=out/stills
node render.mjs --frames --workers=1 --duration=30
node render.mjs --encode --out=out/video.mp4
```

最终帧默认 PNG；`--frame-format=jpg` 只用于快速测试。
