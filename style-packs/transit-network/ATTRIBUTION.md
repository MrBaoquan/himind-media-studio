# Attribution

HiMind original `transit-network` style pack: white-background schematic transit map, line growth, station reveal, interchange pulse, legend and year axis.

The bundled Hefei Metro line names and station names are used in a **schematic demo subset**. They are not an official map and must not be used for navigation. Verify line/station data against official Hefei Metro sources or OpenStreetMap before publishing.

The Taiyuan Metro map linked by the user was used only as a visual reference for layout language (white paper, bold line colors, light blue river, clean labels). No part of that image is bundled or reproduced.

No third-party map tiles or screenshots are used. The renderer and composition are original HiMind code.
