# Whiteboard Explainer

| Time | Shot | What the viewer must read |
| --- | --- | --- |
| 0–1.6s | 标题落笔 | 白板、马克笔、明确主题 |
| 1.6–5.2s | 四步流程 | 需求 → 计划 → 审查 → 成片 |
| 5.2–7.2s | 连接与标注 | 四步是一条可复用的生产链 |
| 7.2–8.6s | 重点圈注 | “可复用”与“反馈闭环” |
| 8.6–10s | 结论 | 沉淀能力，而不是重复劳动 |

## 视觉规则

- 只用白板底色、马克笔线条、少量荧光标记；
- 关键线条与图标全部由 Rough.js 程序化绘制；
- 每个图形使用固定 seed，保证同一时间点可复现；
- 不依赖外部图片、网络字体或远程图标；
- 说明性文字优先短句，单屏不超过四层信息。

## 数据契约

读取 `input/data.json`，支持：

```json
{
  "title": "从想法到成片",
  "subtitle": "一条短视频的四步生产链",
  "steps": [
    {"label":"需求","title":"一句话需求","detail":"AI 识别目标、数据与约束"},
    {"label":"计划","title":"分镜与数据契约","detail":"镜头、时长、素材先确定"},
    {"label":"审查","title":"预览与反馈","detail":"在创作台看见真实画面"},
    {"label":"成片","title":"渲染与交付","detail":"质量门禁通过后输出 MP4"}
  ],
  "conclusion": "沉淀能力，而不是重复劳动",
  "source": "HiMind 自媒体创作台"
}
```
