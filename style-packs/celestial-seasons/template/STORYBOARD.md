# Celestial Seasons

> 30 秒竖屏科普 / 1080×1920 / 30fps / 示意动画，不按真实比例。

## 科学结论

四季的主因不是日地距离，而是：

1. 地球自转轴相对公转轨道法线倾斜约 23.44°；
2. 地轴方向在一年中几乎保持不变；
3. 公转使不同半球在不同时间更朝向太阳；
4. 太阳高度角与白昼长度随季节变化。

## 分镜

| 时间 | 场景 | 观众必须读到 |
| --- | --- | --- |
| 0–6s | 公转轨道 | 地球绕太阳公转，轨道接近圆形 |
| 6–12s | 地轴倾角 | 地轴倾斜 23.44°，方向几乎不变 |
| 12–20s | 北半球夏至 | 北半球更朝向太阳，太阳高度更高、白昼更长 |
| 20–26s | 南半球夏至 | 南半球季节相反 |
| 26–30s | 结论 | 四季 = 地轴倾斜 + 公转，不是距离 |
