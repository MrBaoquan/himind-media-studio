# 线网开通时间轴 · Storyboard

> 38 秒 / 1080×1920 / 30fps / 白底信息图  
> 参考形式：抖音「玩转地球」合肥轨道交通 12/26 时间轴动画（仅分析运动与信息结构，不复制画面）

## 叙事目标

用一条时间轴回答一个问题：

```text
为什么说合肥轨道交通对 12/26 情有独钟？
```

不是做“完整官方线网图”，而是做“开通事件的可视化”：

- 每一条线在开通年份出现；
- 线路从起点生长到终点；
- 站点依次出现；
- 底部同步滚动日期、区段、累计里程；
- 所有事件都落在 12 月 26 日，形成重复记忆点。

## 单个事件内部节奏

```text
0.0–0.2s   底部卡片上滑进入
0.0–2.8s   新线从起点画到终点
0.6–3.2s   站点按沿线距离依次弹出
0.0–3.8s   累计里程从上一值滚动到新值
2.8–5.4s   镜头停留，换乘站脉冲，列车点沿线移动
5.4–6.2s   卡片下移退出，切到下一事件
```

## 视觉规则

- 背景：暖白 `#F4F3EE` + 细点阵；
- 已开通线路：降低到 34% 不透明度；
- 当前线路：官方色 + 白色描边 + 轻微 glow；
- 未来线路：不显示；
- 当前线路站名：全部显示；
- 历史线路：只保留换乘站和终点站标签；
- 底部卡片：日期、线路色块、区段、累计里程、12/26 徽标、年份轨道；
- 里程数字使用等宽字体，滚动计数；
- 站名布局固定，不做逐帧重排。

## 边界

- 当前是示意子集，不是完整官方线网；
- 正式版本应替换为 OSM + 官方公告校验的数据；
- 里程是演示值，正式版应使用官方运营里程；
- 参考视频的版式与素材版权归原作者，本模板只沉淀“时间轴 + 地图生长 + 里程滚动”的通用技法。
