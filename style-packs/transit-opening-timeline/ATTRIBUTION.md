# Attribution

## Composition

HiMind original `transit-opening-timeline` Canvas 2D composition.

The motion grammar was informed by a public Douyin reference:

```text
玩转地球 ·《合肥轨道交通对12/26情有独钟》
https://v.douyin.com/KFMDNA6vIQk/
```

Only the information structure and motion ideas were analyzed:

- date-led timeline;
- network growth by opening event;
- rolling cumulative mileage;
- line/segment caption;
- light schematic map.

No frames, map artwork, audio, or other assets from the reference video are copied into this pack.

## Data

The bundled Hefei data is a **schematic subset** for motion study:

- not an official map;
- not a complete network;
- not for navigation.

For a production version, replace it with:

- OpenStreetMap geometry (ODbL 1.0, © OpenStreetMap contributors);
- official Hefei Metro announcements for station names / opening dates / line colors;
- Wikipedia / Wikidata only as cross-checks.
